# Pengembaraan Bahasa Melayu Tahun 4

## Kandungan
- `index.html` — aplikasi PdP interaktif lengkap, responsif untuk telefon/tablet.
- 4 petikan asli, 20 soalan objektif kefahaman, markah bintang, maklum balas, bunyi, suara peranti (jika tersedia), animasi kemenangan.
- Nota infografik, pautan video YouTube, objektif, dan rujukan DSKP.

## Cara menggunakan
1. Buka `index.html` menggunakan Chrome, Edge, Firefox atau Safari.
2. Masukkan nama murid dan tekan **Mulakan misi**.
3. Aktifkan bunyi jika perlu; pelayar/peranti mungkin meminta interaksi pengguna sebelum audio berfungsi.
4. Untuk menerbitkan ke GitHub Pages:
   - Cipta repositori GitHub baharu.
   - Muat naik `index.html` (boleh juga muat naik README).
   - Buka **Settings → Pages**.
   - Pilih **Deploy from a branch**, pilih `main` dan folder `/ (root)`, kemudian Save.
   - Selepas GitHub Pages selesai menerbitkan, pautan akan kelihatan di bahagian Pages.
5. Jika repositori awam, semua orang yang mempunyai pautan boleh membuka bahan ini.

## Nota
- Suara menggunakan Web Speech API dan bergantung pada suara Bahasa Melayu yang tersedia pada peranti/pelayar. Jika tiada, pelayar mungkin menggunakan suara lalai.
- Audio memerlukan tindakan pengguna dan mungkin disekat oleh tetapan pelayar.
- Video dibuka melalui pautan YouTube; sambungan internet diperlukan.
- Kod ini ialah bahan sokongan PdP. Sila semak kesepadanan nombor SK/SP dengan salinan DSKP rasmi sekolah sebelum digunakan dalam RPH.
